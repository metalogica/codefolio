# rei.gg

Portfolio of Rei Jarram — a PC-98-inspired desktop environment built with Astro,
React, and Tailwind CSS. SSR on Vercel.

## Development

```bash
pnpm install
pnpm dev      # start dev server
pnpm build    # production build
pnpm lint     # eslint
```

Requires `OPENAI_API_KEY` for the terminal chatbot (see `.env.example`).
